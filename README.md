# PROG5112 POE - Chat Application

Complete Portfolio of Evidence for Programming 5112 - IIE Rosebank internationl College.

This repository contains the full POE project from Part 1 to Part 3.

### Part 1: User Registration & Login
- Username validation (must contain _ and max 5 chars)
- Password complexity validation (capital, number, special char, 8+ chars)
- Cellphone number validation with South African code (+27)
- Registration and Login functionality
- Return login status messages

### Part 2: QuickChat Messaging
- Send messages with auto-generated Message ID
- Message Hash creation
- Validate recipient cell number
- Store messages in messages.json
- Display sent messages, longest message, etc.
- JUnit tests for all methods

### Part 3: (In Progress)
- Advanced features, reports, and final enhancements will be added here.
- Coming soon...
